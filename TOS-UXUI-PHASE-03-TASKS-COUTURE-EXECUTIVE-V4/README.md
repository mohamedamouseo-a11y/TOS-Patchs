# Phase 03 — Tasks Couture Executive V4

A major visual escalation for the active Tasks board after V3 review.

Review location:
- TOS → Tasks (`/tasks`)
- Open any project
- Compare the same active board in Light and Dark before/after V4

V4 direction:
- Dark: deeper Obsidian / Black Titanium / Platinum with restrained Champagne hardware.
- Light: Porcelain / Ivory / Champagne with stronger layered depth.
- Workspace Tools becomes an executive command deck.
- KPI rings become jewel-like instruments with stronger contrast.
- Kanban columns gain layered material depth and premium edge highlights.
- Task cards become raised executive cards with richer hierarchy and hover depth.
- Primary board actions use Champagne instead of generic blue.
- Empty states and board footnote are brought into the same premium language.

Reference: approved Phase 02 Projects premium design language.

Presentation only. No business logic, permissions, drag/drop, realtime, Ramzy, TCS, or Help Center behavior changes.

Apply:

```bash
bash TOS-UXUI-PHASE-03-TASKS-COUTURE-EXECUTIVE-V4/apply_phase03_tasks_couture_executive_v4.sh /var/www/TOS
```

Builds and deploys to `/opt/apps/tamiyouz-front/build`. No commit or push is performed on TOS.
