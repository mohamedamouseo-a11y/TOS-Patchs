OBJECTIVE
Fix ONLY the top-header Ramzy avatar/greeting presentation defect visible in the V2.11H screenshots.

The defect to eliminate:
- Ramzy greeting text must NEVER collapse into a narrow vertical word stack.
- Ramzy avatar must remain fully contained in the top-header safe band.
- At 1664x936, greeting/identity copy must render horizontally beside the avatar.
- At 1366x768, keep the previously approved compact avatar-only treatment; greeting/label should remain hidden.
- The Ramzy launcher must not overlap TCS, search, user profile, breadcrumbs, buttons, Task Details Hero or page content.

IMPORTANT
This is NOT a Task Details redesign.
This is NOT a user-profile redesign.
This is NOT a TCS redesign.
This is a CSS-only correction to the closed Ramzy launcher presentation while Task Details V2 is mounted.
