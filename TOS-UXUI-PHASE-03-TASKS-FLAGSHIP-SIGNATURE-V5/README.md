# Phase 03 — Tasks Flagship Signature V5

A stronger visual escalation of the active Tasks board after V4 screenshot review.

Review location:
- TOS → Tasks (`/tasks`)
- Open the same project used for V4
- Compare the active Task Board in Light and Dark before/after V5

Why V5:
- V4 is cleaner, but still reads too much like a polished admin dashboard rather than a flagship executive product screen.
- V5 adds dedicated semantic hooks for the KPI deck, Kanban shell, and Kanban hero so the premium treatment is precise instead of relying only on broad selectors.

V5 targets:
- Signature Workspace command deck.
- Floating KPI instrument pods instead of loose rings.
- Strong flagship Kanban outer frame.
- Sculpted Porcelain / Black Titanium columns with intentional depth in empty areas.
- Raised signature task cards with a restrained Champagne edge.
- Champagne primary board actions, including Design Request.
- Stronger Light and Dark material separation without overfilling surfaces with gold.

Reference: approved Phase 02 Projects premium language.

Presentation only. No task business logic, permissions, drag/drop, realtime, Ramzy, TCS, or Help Center behavior changes.

Apply:

```bash
bash TOS-UXUI-PHASE-03-TASKS-FLAGSHIP-SIGNATURE-V5/apply_phase03_tasks_flagship_signature_v5.sh /var/www/TOS
```

Builds and deploys to `/opt/apps/tamiyouz-front/build`. No commit or push is performed on TOS.
